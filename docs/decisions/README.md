# Décisions inter-devs en attente de ratification

> Ce dossier existait déjà **en référence dans le code** (`scoring.constants.ts`,
> `yield-model.adapter.ts`) sans exister sur le disque. Les fichiers sont créés
> ici pour que ces renvois pointent vers quelque chose de réel.

Une décision listée ici est un **choix pris unilatéralement pour ne pas bloquer**,
avec une valeur par défaut assumée, en attendant l'accord des personnes
concernées. Ce n'est ni un ADR (réservé aux décisions structurantes actées,
voir [`../adr/`](../adr/)), ni une exigence.

Cycle de vie : `en attente` → ratifiée (valeur consignée dans le document de
référence : `contrat-systeme.md` pour une règle métier, un ADR si la décision
est structurante) → la ligne est retirée d'ici.
