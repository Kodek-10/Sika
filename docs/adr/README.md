# Architecture Decision Records (ADR)

> Une décision structurante doit avoir un ADR. Ne jamais supprimer un ADR historique — un ADR remplacé est marqué `[REMPLACÉ PAR ADR-00X]` en tête, pas effacé.

## Format d'un ADR

Chaque ADR répond à : quel était le problème, quelles options ont été considérées, quelle décision a été prise, pourquoi, et quelles conséquences elle entraîne (y compris les inconvénients assumés).
