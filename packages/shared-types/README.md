# Shared Types — `packages/shared-types/`

> Propriétaire : commun aux 3 devs
> Règle : ajout libre, mais **jamais de modification d'un type existant sans prévenir les deux autres devs** — voir [Guide de collaboration](../../docs/COLLABORATION.md) section 1.

Types partagés entre `apps/backend/`, `apps/field-app/` et `packages/payments/` — notamment les formes de `Declaration`, `Score`, `Producer`, `Alert` utilisées côté API (voir [`apps/backend/docs/API.md`](../../apps/backend/docs/API.md) pour les schémas de référence).
